Discharge a scoped assumption

Runnable RiX

Subproof inserts the assumption as its first local line. The outer proof sees only the checked subproof record, not its assumption as a freely usable outer premise. Additional free premise and assumption lines are rejected inside this first self-contained subproof model. This makes implication introduction a real scope operation; a later outer-line import feature will need to name and replay every imported dependency explicitly.

Reason by cases

Runnable RiX

Both cases must start from the corresponding disjunct and reach exactly the same conclusion. Reversing the two case records is allowed; omitting a case or changing either goal is rejected.
