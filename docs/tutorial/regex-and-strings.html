Regexes and strings

Pattern literals and text transformation.

Slice text

Regex literals support matching modes, while strings support indexes, slices, and methods. Keep matching and replacement logic as small testable expressions.

Runnable RiX

The slice is Rat: string positions begin at 1 and both endpoints are included. See Strings and tuples for individual characters.

Test a pattern

A regex literal is a callable pattern. The ? mode asks only whether any digit occurs; it returns true (1) or false (_).

Runnable RiX

Without ?, a matching regex returns a match object with text and position information. Use that when the match itself matters, then pass results through a pipe if several strings need testing.
