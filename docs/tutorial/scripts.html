Scripts and extensions

RiX modules, host boundaries, and language extension.

Orientation

RiX scripts can declare interfaces, import other RiX files, and run inside capability frames. JavaScript modules and language extensions are host-level features with explicit trust boundaries.

Prerequisites: Functions, Scope and imports, and System capabilities. Start with RiX scripts for a program you want to reuse. Read JavaScript modules only when a host needs to provide behavior from JavaScript, and Language extensions when changing parsing or dispatch. JavaScript-to-RiX gotchas is optional early reading for experienced programmers.
