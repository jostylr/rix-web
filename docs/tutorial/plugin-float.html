Optional Float math

RiX exact Integers and Rationals are always available. Load float when a calculation intentionally needs IEEE-754 behavior:

Runnable RiX

The package owns the Float semantic type and the .float command namespace. This keeps other future numerical plugins—interval oracles, Cauchy sequences, continued fractions—from competing for a single global approximate type.

For display-oriented decimal work, rounding is explicit:

Runnable RiX

The results preserve the actual stored IEEE value, rather than pretending that the input was a decimal real number.
